Cadastro

  1. Abra Configurações e escolha Cadastrar evolutiva para acompanhar um cronograma.
  2. Informe o nome e envie um arquivo .xml, .mpp ou .mpt, indique uma origem, ou preencha Informações para cadastrar como Em construção.
  3. Use Cadastrar evolutiva em estudo quando ainda não houver cronograma definido.

Estudos

  1. Use o ícone de lápis ao lado do título para alterar título e descrição.
  2. Quando a evolutiva sair da fase de estudo, cadastre-a como evolutiva com cronograma.
  3. Use Excluir apenas quando o estudo não precisar mais aparecer no painel.

Acompanhamento

  1. Use o ícone de lápis ao lado do título para renomear evolutivas já cadastradas.
  2. Abra uma evolutiva para ver tarefas, planejado, realizado, desvio, atrasos e pontos de atenção.
  3. Use os filtros de tarefas para focar em Atenção, Atrasadas ou Em andamento.
  4. Atualizar cronograma substitui o arquivo usado nas métricas da evolutiva; em evolutivas Em construção, essa ação transforma o cadastro em evolutiva acompanhada.
  5. Use Exportar PDF para gerar um relatório executivo do dashboard, pronto para leitura gerencial.
  6. No Dashboard, arraste os cards para organizar a ordem dentro de Evolutivas ou Estudos.
  7. A gestão abre filtrada em Em andamento. Use Todos, Em andamento ou Concluídos para filtrar evolutivas e estudos. Nos cards, use Concluir projeto ou Reabrir projeto para evolutivas e Concluir estudo ou Reabrir estudo para estudos; as ações não exigem login nem alteram as etapas das atividades.

Status report

  1. Abra a evolutiva e clique em Gerar status report.
  2. Revise o texto gerado e copie para enviar por e-mail.
  3. Use Informações para registrar observações internas da evolutiva.

Assistente de gestão da Reforma Tributária

  1. Somente administradores veem o Assistente de gestão. No Kanban do projeto Reforma Tributária - escopo Novas taxas e Novas adequações fiscais, use-o para consultar status, riscos, cobranças, responsáveis, distribuição de trabalho, próximas ações ou pauta de reunião.
  2. Sem uma chave OpenAI configurada, as respostas usam regras internas. Com a chave ativa, a pergunta, o histórico recente e campos dos cards são enviados à API OpenAI; o assistente não altera cards nem envia mensagens automaticamente.
  3. Para uma cobrança, selecione Preparar cobrança. Revise o rascunho na conversa da atividade, confirme a pessoa mencionada e clique em Enviar mensagem somente quando estiver pronto.
  4. Atividades na etapa Em Homol aguardam o cliente. Elas aparecem separadamente e não contam como atraso nem geram cobrança para a equipe interna.

Gestão de atividades

  1. Abra uma evolutiva e encontre a área Atividades do projeto. Selecione Nova atividade para começar.
  2. Escolha o tipo: Análise de Requisitos, Definição Técnica ou Bug. Para bugs, informe severidade, ambiente, passos para reproduzir e resultados esperado e observado. Em Definição Técnica, informe até três links do código no GitHub, tipificados como Frontend, Backend e Serviço, além do pacote de implantação, se disponíveis.
  3. Use a barra visual na Descrição para aplicar formatação. Cole imagens com Ctrl+V ou selecione Imagem. As mudanças são enviadas junto com Salvar atividade.
  4. Vincule uma Definição Técnica à Análise de Requisitos correspondente. Vincule cada bug à Definição Técnica afetada.
  5. Defina responsável, prioridade e prazo. Use Próxima ação para registrar o próximo passo objetivo.
  6. Informe a Etapa e salve. Para dividir o trabalho, adicione itens ao Checklist e marque cada etapa conforme concluir.

Etapas e bloqueios

  1. As listas do Kanban representam a Etapa do card. Arraste o card para outra lista ou use Mover para no menu do card.
  2. Análises de Requisitos passam por Não iniciada, Em análise, Aprovada ou Bloqueada. Definições Técnicas passam por Não iniciada, Em definição, Pronta para teste, Em teste, Concluída ou Bloqueada.
  3. Bugs passam por Aberto, Em correção, Pronto para reteste, Bloqueado ou Fechado. Severidade representa impacto; prioridade representa ordem de trabalho.
  4. Use Bloqueada por outro motivo e informe a razão quando houver um impedimento manual. Bugs pendentes também aparecem como alerta na Definição Técnica e não alteram sua Etapa.
  5. Depois que todos os bugs vinculados forem fechados ou arquivados, o alerta de pendência desaparece. A equipe atualiza a Etapa da Definição Técnica conforme o avanço real.

Kanban e filtros

  1. Use Kanban, Lista ou Por etapa para alternar a visualização. A última escolha fica salva neste navegador para sua conta e é aplicada ao abrir qualquer evolutiva.
  2. Use os filtros para ver tipos de atividade, atrasos, bloqueios ou itens sem responsável. O filtro de responsável dentro de cada lista também permite escolher Sem responsável.
  3. Segure a barra de espaço e arraste com o mouse para deslocar o quadro. As listas também permitem rolagem vertical.
  4. Abra o menu do card para mover, editar ou arquivar a atividade. Use o painel lateral do projeto para acessar resumo e ações do projeto.

Conversa, menções e evidências

  1. Abra um card salvo e escolha Conversa para registrar decisões e dúvidas. Use Responder para manter o contexto da conversa.
  2. Digite @ e selecione uma pessoa na lista sugerida. A pessoa selecionada e o responsável pelo card podem receber uma notificação no painel e por e-mail. O autor da mensagem não recebe notificação de si mesmo.
  3. Na aba Evidências, arraste arquivos, selecione-os ou cole uma captura com Ctrl+V. Cada arquivo pode ter até 20 MB.
  4. Consulte Histórico para ver as alterações registradas na atividade.

Preferências e acesso

  1. Use o ícone de lua no cabeçalho para ativar o modo escuro; o ícone de sol volta ao modo claro. A escolha fica salva neste navegador.
  2. É necessário entrar com uma conta ativa para criar ou editar atividades, conversar, anexar evidências e receber notificações pessoais.
  3. Se uma menção não gerar aviso, confira se selecionou a pessoa na lista após digitar @. Escrever o nome sem selecionar não cria uma menção.
