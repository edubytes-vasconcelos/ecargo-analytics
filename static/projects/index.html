Manual de uso

Cadastro

  1. Abra Configurações e escolha Cadastrar projeto para acompanhar um cronograma.
  2. Informe o nome e envie um arquivo .xml, .mpp ou .mpt, ou indique uma pasta local ou URL do SharePoint.
  3. Use Cadastrar projeto em estudo quando ainda não houver cronograma definido.

Estudos

  1. Use Editar estudo para alterar título e descrição.
  2. Quando o projeto sair da fase de estudo, cadastre-o como projeto com cronograma.
  3. Use Excluir apenas quando o estudo não precisar mais aparecer no painel.

Acompanhamento

  1. Use Editar título para renomear projetos já cadastrados.
  2. Abra um projeto para ver tarefas, planejado, realizado, desvio, atrasos e pontos de atenção.
  3. Use os filtros de tarefas para focar em Atenção, Atrasadas ou Em andamento.
  4. Atualizar cronograma substitui o arquivo usado nas métricas do projeto.
  5. No Dashboard, arraste os cards para organizar a ordem dentro de Projetos ou Estudos.

Status report

  1. Abra o projeto e clique em Gerar status report.
  2. Revise o texto gerado e copie para enviar por e-mail.
  3. Use Informações para registrar observações internas do projeto.
